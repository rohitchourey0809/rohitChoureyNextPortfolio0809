# 🚀 Rohit Chourey | Portfolio

A modern, responsive, and interactive **Full Stack Developer Portfolio** built with **Next.js**, **React**, **Tailwind CSS**, and **Framer Motion**. It showcases my professional experience, technical skills, featured projects, GitHub activity, and contact information in a clean and user-friendly interface.

## ✨ Features

* 🚀 Built with **Next.js 15** and **React**
* 🎨 Modern UI with **Tailwind CSS**
* 🎥 Smooth animations using **Framer Motion**
* 📱 Fully responsive across all devices
* 💼 Professional Hero, About, Skills, Experience, and Projects sections
* 🛠️ Interactive project showcase with live demo and source code links
* 📊 GitHub statistics integration
* 📬 Contact form powered by **Formspree**
* ⚡ Optimized performance and SEO
* 🌙 Clean dark-themed developer portfolio

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/rohitchourey0809/rohitchoureynextportfio0809.git
```

### Navigate to the project

```bash
cd rohitchoureynextportfio0809
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open **http://localhost:3000** in your browser.
